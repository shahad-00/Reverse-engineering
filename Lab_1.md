# Lab 1: Setting Up the Reverse Engineering Environment

- Download and install VirtualBox to run a virtual machine.
- Set up and run Kali Linux inside VirtualBox.
- Install GCC to compile C programs and the JDK to develop and compile Java programs.
- Check the tool versions using:

```bash
gcc --version
javac -version
```

## Reference

Yurichev, Denis. *Reverse Engineering for Beginners*.
